# OPEN WORLD (Web & Mobile)

**A wordless, procedurally generated wandering game for phone and browser** — faithful web port of [bradflaugher/open-world](https://github.com/bradflaugher/open-world) (Game Boy / Game Boy Color).

**Play it:** https://open-world.win/

## What's inside

- **360° Horizon Compass:** Distant parallax mountains turn smoothly as you turn, showing the three Beacons, the Heart, your nearest cairn, and the nearest wisp glint at their true bearings.
- **Kid-friendly phone controls:** Drag anywhere on the screen with a floating virtual thumbstick (push to the rim to sprint), or simply tap anywhere to walk there. A single glowing smart **Act** button automatically uses the right item for whatever you're facing.
- **Three Beacons & the Heart:** Burn brambles with the **Lantern**, bridge shallows and build persistent **Cairns** with **Stones**, glide across crags with the **Cloak**, and reach **the Heart** to dissolve into a fresh seeded world where your cairns remain as ancient ruins.
- **Wisps & Permanent Stars:** Catch glowing wisps over open ground to raise them into the night sky (from 3 up to 28 permanent stars across worlds).
- **Browser flair:** 60 fps atmospheric day/dusk/night lighting with volumetric lantern & campfire glow, rain/snow/fog weather, startled birds, fireflies, Watchers, a generative Eno-style Web Audio soundtrack, and a 1-tap **1989 Game Boy DMG Green** palette toggle.

## Running locally

```sh
npm install
npm test
npm run lint
npm start
```
